# SoftSkill Compatibility Package

This directory intentionally remains named `skillopt` so existing SkillOpt
configs, scripts, tests, and checkpoint artifacts continue to import correctly.

SoftSkill-specific code lives primarily in `skillopt/softprefix/`. Several
hard-skill training components, benchmark adapters, prompts, and initial skill
documents are retained from the SkillOpt-derived codebase under the MIT License
and are used for compatibility and baseline comparison.

This directory is derived from Microsoft [SkillOpt](https://github.com/microsoft/SkillOpt/).
